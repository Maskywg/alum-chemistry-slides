由鋁罐製作明礬

鋁罐裡的鋁，能變成透明晶體。

從金屬到溶液，再到晶體。

金屬鋁 → 溶液中的鋁 → 明礬晶體

明礬：KAl(SO₄)₂·12H₂O

原理與形狀示意 · 非實驗實拍

本頁講稿

今天追蹤的是鋁的去向。鋁罐不是直接變成晶體，而是先發生化學反應，最後透過結晶取得新物質。封面的晶體是形狀示意，不是實驗照片。

01 / 看懂路線

先溶解，再結晶，是整個實驗的主線。

每一步，都在改變鋁的存在形式。

處理鋁片 → 鹼中溶解 → 過濾

加酸轉換 → 冷卻結晶 → 分離乾燥

原理與形狀示意 · 非實驗實拍

本頁講稿

先給聽眾一張路線圖。前半段是化學轉換；後半段利用溶解度差異分離產物。過濾的時機不同，留下的東西也不同。

02 / 準備鋁片

去除表面塗層，讓試劑接觸鋁。

鋁罐表面有塗層，處理後再稱量。

依講義去除內外塗層，剪成小片

記錄鋁片質量；注意金屬銳邊

原理與形狀示意 · 非實驗實拍

本頁講稿

鋁罐不只有鋁，也有塗層與合金成分。依老師提供的方法去除表面塗層。質量記錄是後面計算產率的基礎；不要把整個罐子的重量當成純鋁質量。

03 / 金屬進入溶液

鋁在鹼中溶解，同時放出氫氣。

KOH 提供鹼性環境，也帶入 K⁺。

2Al + 2OH⁻ + 6H₂O

→ 2[Al(OH)₄]⁻ + 3H₂↑

原理與形狀示意 · 非實驗實拍

本頁講稿

這是氧化還原反應：鋁由零價轉為三價，水中的氫被還原為氫氣。鋁以四羥基合鋁酸根存在。氣泡並非沸騰的證據。氫氣易燃，須在通風櫥依指導操作，遠離火源；不可密閉。

04 / 分開雜質

第一次過濾，要留下含鋁的濾液。

溶解的含鋁物種通過濾紙。

濾紙上：不溶的殘渣

下方濾液：保留，進入下一步

原理與形狀示意 · 非實驗實拍

本頁講稿

這一步不是把明礬濾出來。明礬尚未形成，目標鋁仍在溶液中。第一次過濾留下濾液，最後結晶後才收集固體。濾液仍有腐蝕性。

05 / 酸化轉換

加酸改變鋁的存在形式，也帶入硫酸根。

可能先看見白色沉澱，再逐漸溶解。

[Al(OH)₄]⁻ + H⁺ → Al(OH)₃↓ + H₂O

Al(OH)₃ + 3H⁺ → Al³⁺ + 3H₂O

原理與形狀示意 · 非實驗實拍

本頁講稿

先中和多餘的鹼，條件改變時可出現白色氫氧化鋁，再於足夠酸性下溶解。白色沉澱不是明礬晶體。酸鹼混合會放熱，依講義慢慢加入並攪拌，勿自行套用其他教材的濃度用量。

CHEMISTRY / MATERIAL TRANSFORMATION化學實驗 · 概念試作

06 / 結晶成形

冷卻降低溶解度，讓明礬長成晶體。

離子與水分子，在晶體中規則排列。

K⁺ + Al³⁺ + 2SO₄²⁻ + 12H₂O

→ KAl(SO₄)₂·12H₂O(s)

原理與形狀示意 · 非實驗實拍

本頁講稿

當溶液條件合適，冷卻可使溶液過飽和而析出晶體。不要說所有冷卻的溶液都一定結晶。十二個水分子是化學式中的結晶水；圖中離子數量、距離與晶體外形是示意，沒有呈現真實晶格或完整水合結構。

07 / 回收產物

最後收集的是晶體，洗滌與乾燥影響產率。

分離晶體後，依講義少量冷洗液洗滌。

收集晶體 → 洗滌 → 按規範乾燥 → 稱量

殘留母液會使量到的質量偏高

原理與形狀示意 · 非實驗實拍

本頁講稿

最後的過濾與前面不同，這時留下固體。洗液溫度與用量會影響產物溶失。乾燥是去除表面洗液，不能任意高溫烘烤，以免改變水合狀態。廢液依實驗室規範分類回收，不採用其他教材的排放建議。

CHEMISTRY / MATERIAL TRANSFORMATION化學實驗 · 概念試作

08 / 解讀結果

晶體比原本的鋁重，因為加入了其他成分。

假設鋁為限制試劑，1 mol Al 對應 1 mol 明礬。

理論明礬質量 = 純鋁質量 × 17.58

產率 = 實得質量 ÷ 理論質量 × 100%

原理與形狀示意 · 非實驗實拍

本頁講稿

這不是質量憑空增加，鉀、硫酸根和結晶水都進入產物。17.58是摩爾質量之比，前提是鋁為限制試劑、樣品為純鋁且產物為十二水合明礬。真實鋁罐含合金與殘留物，需依講義修正。超過100%不代表更成功，可能是濕晶體或雜質。

09 / 帶走三個觀念

看懂物質轉換，也要看懂每一步的風險。

鋁沒有消失；它進入了新的化合物。

護目鏡、實驗衣、適用手套；氫氣遠離火源

強酸強鹼由教師指導；產物不可食用

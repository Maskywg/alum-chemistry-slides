由鋁罐製作明礬

01 / 看懂路線

先溶解，再結晶，是整個實驗的主線。

每一步，都在改變鋁的存在形式。

處理鋁片 → 鹼中溶解 → 過濾

加酸轉換 → 冷卻結晶 → 分離乾燥

02 / 準備鋁片

去除表面塗層，讓試劑接觸鋁。

鋁罐表面有塗層，處理後再稱量。

依講義去除內外塗層，剪成小片

記錄鋁片質量；注意金屬銳邊

03 / 金屬進入溶液

鋁在鹼中溶解，同時放出氫氣。

KOH 提供鹼性環境，也帶入 K⁺。

2Al + 2OH⁻ + 6H₂O

→ 2[Al(OH)₄]⁻ + 3H₂↑

04 / 分開雜質

第一次過濾，要留下含鋁的濾液。

溶解的含鋁物種通過濾紙。

濾紙上：不溶的殘渣

下方濾液：保留，進入下一步

05 / 酸化轉換

加酸改變鋁的存在形式，也帶入硫酸根。

可能先看見白色沉澱，再逐漸溶解。

[Al(OH)₄]⁻ + H⁺ → Al(OH)₃↓ + H₂O

Al(OH)₃ + 3H⁺ → Al³⁺ + 3H₂O

06 / 結晶成形

冷卻降低溶解度，讓明礬長成晶體。

離子與水分子，在晶體中規則排列。

K⁺ + Al³⁺ + 2SO₄²⁻ + 12H₂O

→ KAl(SO₄)₂·12H₂O(s)

07 / 回收產物

最後收集的是晶體，洗滌與乾燥影響產率。

分離晶體後，依講義少量冷洗液洗滌。

收集晶體 → 洗滌 → 按規範乾燥 → 稱量

殘留母液會使量到的質量偏高

08 / 解讀結果

晶體比原本的鋁重，因為加入了其他成分。

假設鋁為限制試劑，1 mol Al 對應 1 mol 明礬。

理論明礬質量 = 純鋁質量 × 17.58

產率 = 實得質量 ÷ 理論質量 × 100%

09 / 帶走三個觀念

看懂物質轉換，也要看懂每一步的風險。

鋁沒有消失；它進入了新的化合物。

護目鏡、實驗衣、適用手套；氫氣遠離火源

強酸強鹼由教師指導；產物不可食用
